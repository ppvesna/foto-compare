```

│                        ЗАГРУЗКА ФОТО                                │
├───────────────────────┬─────────────────────────────────────────────┤

│  │  Коррекция      │   │  Сшивка кадров   │   │  Кроп рамкой     │  │

│           → грубое совмещение при больших смещениях/повороте         │
│                                                                      │

                           │
                           ▼
```

## Приоритет итогового балла
```
Lab score (OpenCV) > SSIM > MAE (Dart)
```

## Каноническое разрешение
```
70 л/см × 2 (Найквист) × размер_мм = px → округление до кратного 27
Дефолт: 100×100 мм → 1404×1404 px
```
