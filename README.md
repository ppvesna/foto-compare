# 📸 Photo Compare — Dev Assistant Instruction v3

## 🎯 Сценарии использования

### Сценарий 1 — Цифровой файл vs Распечатка
**Задача:** проверить, совпадает ли распечатка с оригинальным файлом.

1. В слот **Эталон** загружается цифровой файл (JPEG/PNG)
2. Распечатку фотографируют камерой телефона
3. Полученное фото загружается в слот **Сравниваемое**
4. Пользователь выравнивает распечатку в рамке (фон стола/стены отбрасывается)
5. Приложение сравнивает и показывает % схожести + карту различий

**Практические применения:**
- Контроль качества печати (точность цвета, детали)
- Проверка, что распечатан правильный файл
- Выявление дефектов принтера (полосы, пятна, пересветы)

---

### Сценарий 2 — Первая распечатка vs Новые распечатки
**Задача:** сравнивать все последующие распечатки с эталонной первой.

1. Первая распечатка фотографируется и сохраняется как **Эталон**
2. Каждая новая распечатка фотографируется и сравнивается с эталоном
3. История сравнений показывает, как менялось качество со временем

**Практические применения:**
- Контроль стабильности принтера (выгорание картриджа, смещение)
- Приёмка тиражей — быстрая проверка партии
- Сравнение разных принтеров между собой

---

### Ключевые особенности алгоритма для печати
- **Рамка захвата** — изолирует объект от фона (стол, рука и т.д.)
- **_fitCrop + центральный кроп** — приводит оба изображения к одному масштабу
- **Карта различий** — прозрачный оверлей: зелёный (4–20%), жёлтый (20–45%), красный (>45%)
- **Нормализация цвета** *(планируется)* — компенсирует цветовой сдвиг принтера

Photo Compare — Flutter-приложение для сравнения изображений с эталоном (визуально и метриками).

Платформы:
- Flutter Web (текущая, работает в браузере)
- Flutter Android / iOS (следующий этап)

UI стиль: Windows XP (намеренно, как фирменный стиль)

Бэкенд: Supabase (Auth + БД), SQLite локально

Стратегия:
1. MVP (локально, быстро) ← текущий этап
2. Расширение (метрики, AI)
3. Масштабирование (облако, синхронизация)

## 📊 Метрики

Текущее:
- MAE (Mean Absolute Error) → % схожести ✅

Планируется:
- SSIM (структурное сходство)
- PSNR (отношение сигнал/шум)
- MSE

```dart
class MetricResult {
  final double similarity; // MAE-based, уже есть
  final double? ssim;      // планируется
  final double? psnr;      // планируется
  final double? mse;       // планируется
}
```

Отображение:
- числовые значения
- интерпретация (высокая / средняя / низкая схожесть)

## 🤖 AI-блок

Текущее: `featureAI = false` (выключено, заготовка через Claude API)

Планируемые функции:
- `enhance()` — улучшение качества
- `normalize()` — нормализация яркости/цвета
- `align(reference, test)` — выравнивание
- `detectArtifacts()` — обнаружение артефактов

Правила:
- включается через feature flags (`AppConfig.featureAI`)
- сначала простые алгоритмы / заглушки
- потом Claude API или локальные модели
