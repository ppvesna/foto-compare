# Правила работы с пользователем

- **Без команды "Делай" — не делать.** Если пользователь присылает информацию, схему,
  описание проблемы или идею — сначала прочитать, проанализировать, при необходимости
  обсудить/задать вопросы. Изменения в коде, коммиты и другие действия — только после
  явной команды "Делай" / "Начинай".
- Если пользователь пишет "надо обсудить" — переходим в режим обсуждения, без правок кода.
