## Известные ограничения

- Встроенная почта Supabase может ограничивать частые тестовые письма.
- Если приглашение сохранено, но email не отправлен, уже подтверждённый
  аккаунт может войти обычным email/пароль и завершить приглашение.
- Смена пароля внутри аккаунта реализована; восстановление забытого пароля по
  письму со страницы входа ещё не подключено.
- Один пользователь сейчас может состоять только в одной организации.
- Имя активного представителя сейчас хранится в общем `user_profiles`, поэтому
  исправление видно во всём его аккаунте. До поддержки участия одного человека
  в нескольких организациях понадобится отдельное имя внутри организации.
- Реальные платежи, Google Drive, PDF, production-лицензии и полная
  cloud/local-first синхронизация ещё не завершены.
- Обычные вложения пока доступны только в чатах работ, ограничены 10 МБ и не
  имеют отдельного интерфейса удаления; срок хранения равен сроку хранения
  самой работы.
- Встроенный боковой браузер Codex один раз оборвал Flutter debug-сессию при открытии
  системного file picker; тот же сценарий в отдельном браузере прошёл. Это ограничение
  локальной тестовой среды, а не подтверждённый дефект продукта.
- Web является основной тесируемой платформой; Android требует отдельной
  регрессии, iOS пока не подтверждён.
