  совмещение, Delta E, ч/б геометрия, наложение, лупа и протокол.
- В «Настройки» → «Камера» добавлен мастер калибровочного профиля:
  фиксация камеры, объектива, света, фильтра и условия M0/M1/M2/M3;
  фото шкалы; выбор полей; ввод приборных `L*a*b*` и необязательных

  ошибки. Профиль включается явно только после проверки и применяется к

  Общая карта сравнения и итоговый балл на этом этапе не изменяются.
- Экран сравнения в рабочем дереве переведён в полноэкранный режим: постоянные
  боковые колонки убраны, две верхние панели объединены, показываются только
  текущий этап, активное состояние и нижняя строка параметров. Три зоны выводят
  свободный текст без постоянных карточек; нижняя строка не является кнопкой.
  Справа показана только актуальная HUD-рекомендация и восемь тонких делений
  прогресса; названия и номера этапов постоянно на экран не выводятся. Весь
  порядок, полные данные и протоколы доступны через верхнее меню. После
  получения результа режимы `ΔE / Геометрия ЧБ / Наложение /
  Контроль точки` собраны в одну компактную строку под картой; лупа
  вынесена отдельно на саму карту.
- Основные экраны приведены к общей холодной серо‑графитовой палитре с

  Четыре маленькие полупрозрачные кнопки `Главная / Сравнение / Чат / Настройки`

## Известные ограничения

- Текущий вариант компоновки и стиля экрана сравнения зафиксирован. Правила
  зелёной/красной подсветки отложены: к ним нужно вернуться после фиксации реальных
  допусков для сходства, `ΔE` и плотностей. До этого не трактовать текущие цвета как окончательную
  метрологическую классификацию.
- Встроенная почта Supabase ограничена двумя Auth-письмами в час на весь проект.
  Для регулярного тестирования и production понадобится собственный SMTP.
- Если приглашение сохранено, но email не отправлен, уже подтверждённый
  аккаунт может войти обычным email/пароль и завершить приглашение.
- Восстановление забытого пароля реализовано; финальный ручной проход смены пароля
  по новой ссылке ожидает восстановления почтового лимита Supabase.
- Один пользователь сейчас может состоять только в одной организации.
- Имя активного представителя сейчас хранится в общем `user_profiles`, поэтому
  исправление видно во всём его аккаунте. До поддержки участия одного человека
  в нескольких организациях понадобится отдельное имя внутри организации.
- Реальные платежи, Google Drive, PDF, production-лицензии и полная
  cloud/local-first синхронизация ещё не завершены.
- Обычные вложения пока доступны только в чатах работ, ограничены 10 МБ и не
  имеют отдельного интерфейса удаления; срок хранения равен сроку хранения
  самой работы.
- Калибровочный профиль пока применяется только к «Контрольной точке». Без
  проверенных приборных плотностей `Dc / Dm / Dy / Dk` остаются относительными по RGB.
  Калибровка всей карты ΔE и итогового балла — отдельный следующий этап после
  физической проверки профиля на реальной шкале.
- Встроенный боковой браузер Codex один раз оборвал Flutter debug-сессию при открытии
  системного file picker; тот же сценарий в отдельном браузере прошёл. Это ограничение
  локальной тестовой среды, а не подтверждённый дефект продукта.
- Падение вкладки Chromium на старте сравнения воспроизвелось дважды с одними
  файлами. Flutter-сервер не падал и Dart-исключения не было: вкладку завершал браузер
  из-за пиковой памяти Web Worker. Ограничение размера не вводилось: убраны две
  полные Lab-матрицы и матрицы градиентов, карты PNG кодируются последовательно.
  Формула цвета и размер карты не изменены; нужен ручной повтор с теми же файлами.
- Web является основной тесируемой платформой; Android требует отдельной
  регрессии, iOS пока не подтверждён.
