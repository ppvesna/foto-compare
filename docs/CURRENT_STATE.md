## Известные ограничения

- После создания заказчика в настройках уже открытый экран «Сравнение» не
  обновляет список заказчиков автоматически; новая запись появляется только
  после полной перезагрузки страницы. Нужно добавить явное обновление данных
  при возврате на экран или после изменения справочника.
- Поле/строка номера текущей работы на экране сравнения слишком короткое и
  визуально обрезает длинные номера вроде `VESNA-ISOLATION-TEST-002`. Нужно
  увеличить доступную ширину и обеспечить просмотр полного значения.
- При попытке пригласить участника сверх лимита общая форма заказчика очищается
  и показывает вводящее в заблуждение
  сообщение «Заказчик сохранён, приглашение не отправлено / данные не потеряны».
  Ожидающая запись при этом не создаётся. Нужно сохранять введённые поля и явно
  показывать ошибку лимита мест без предложения вводить данные заново.
- Встроенная почта Supabase может ограничивать частые тестовые письма.
- Если приглашение сохранено, но email не отправлен, уже подтверждённый
  аккаунт может войти обычным email/пароль и завершить приглашение.
- Смена и восстановление пароля внутри приложения ещё не реализованы.
- Один пользователь сейчас может состоять только в одной организации.
- Реальные платежи, Google Drive, PDF, production-лицензии и полная
  cloud/local-first синхронизация ещё не завершены.
- Web является основной тесируемой платформой; Android требует отдельной
  регрессии, iOS пока не подтверждён.
