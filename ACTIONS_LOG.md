# Краткий журнал действ

Этот файл хранит только крупные технические вехи. Детали текущей работы находятся в
[`SESSION_CHANGES.md`](SESSION_CHANGES.md), а план в [`PLAN_NEXT_STAGE.md`](PLAN_NEXT_STAGE.md).

## Реализовано

- Авторизация Supabase email/password с профилем, ником и организацией.
- Четыре основных раздела: Главная, Сравнение, Чат, Настройки.
- Сохранение нескольких эталонов с профилями калибровки.
- Номер работы, ID эталона, ID образца и нумерация отпечатков.
- Калибровка по 4–8 парным точкам с лупой и контрастным уточнением.
- Выравнивание similarity/affine/perspective с Dart-фолбэком и Android OpenCV.
- Режимы результа: Delta E, геометрия Ч/Б, наложение, параметры точки и лупа области.
- Проверка OCR, штрихкодов/QR и Lab ID.
- Локальный список протоколов по отпечаткам.
- Камера, калибровка, допуск Delta E и производственные параметры в настройках.

## Производительность

- Введена предварительная Delta E уровня 2.
- Точная Delta E рассчитывается по запросу.
- Обрезка и сравнение в web вынесены в Web Worker.
- Delta E считается тайлами с прогрессом.
- В протокол добавлены замеры времени обрезки, совмещения и проверок.

Коммит пакета ускорения: `3f8fcd8 Speed up web image comparison`.
